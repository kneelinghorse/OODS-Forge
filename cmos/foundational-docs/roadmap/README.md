# Roadmap

The live roadmap is `near.md`. Since 2026-09-12 it is the multi-phase, multi-sprint plan that follows the
Product Reality Program: palette, application craft, charts, availability to individuals, the design
surface, and Forge's slices of the design-platform vision. Its section 10 places every item the previous
roadmap left open.

## Authoring convention

1. `near.md` names the phases and sprints and links each sprint's locked memo and CMOS record once the sprint is locked.
2. Mission IDs and detailed acceptance criteria live in the locked memo and CMOS, not here.
3. Every open item from a review lands in section 10 with a sprint or a stated park; nothing is dropped silently.
4. Audit dates are allowed; calendar delivery promises are not. The pacing unit is reviewed sprints.
5. Sprint reviews open by saying where we are in plain words: what works, what does not, what Derek can do with it today.

## Pacing

`near.md` updates after each sprint's independent review and at any planning session that changes the
phase order. The program document changes only when Derek changes product direction.
