### Findings

- **[MAJOR / EVIDENCE] "Style Dictionary v5 — Forge's existing chain" is false.** Root `package.json:207` pins `style-dictionary: ^4.4.0` (with `@tokens-studio/sd-transforms 1.3.0` per lockfile). - **[MAJOR / EVIDENCE] Load-bearing numbers rest on weak or mismatched sources.** Specifically: (a) the *only* effort estimate in Move 1 — "1–2 weeks for a 200–500-token inventory" — comes from atomize.tools, an unknown blog; (b) "brand #3 costs 10–20% of the initial build" is a single Medium post (Grönboldt) promoted to a cost curve; (c) the CSA Singapore supply-chain advisory (AD-2026-003) is cited to support "no delivery literature shows an enterprise adopting a consultant's build environment" — a national cyber advisory does not establish design-system delivery practice, and the claim is an unfalsifiable absence claim; (d) newideamachine.com ("every source on agency handoffs says...") and pathtoproject.com ("systems without explicit governance fail", slug dated 2026-04-01) read as content-farm sources carrying strong causal claims.
- **[MAJOR / PREMISE] The recommendation is settled before the two questions that could invalidate it.** Open questions 1 (commercial shape) and 6 (tokens-only vs componentry) are admitted unknowns, yet the deliverable shape is derived from Forge's strongest layer ("exactly Forge's most standards-aligned layer") — reasoning from the factory's strengths toward the client's need. If PT actually engaged Derek for a Figma library + component guidance for their designers, the tokens-repo shape is secondary. The recommendation should be stated as conditional on Q6, not as decided.
- **[MAJOR / COMPLETENESS] Move 2 — the largest engineering item — has no size.** Move 1 gets "week 1–2"; the brand-CSS generator, enum widening, font pipeline, and viz-palette work get no estimate at all, and Move 2 is precisely what competes with Memo 2's crawl phase for the same solo operator's time.

The memo applies enterprise-IT approval scrutiny only to Option 4's hosted MCP endpoint; the same procurement/security gate applies to these SaaS paths.
- **[MINOR / PREMISE] The certify paragraph serves Forge, not PT.** "The milestone where Forge's differentiator... becomes real for this client" names no PT-side driver for certification. A real one exists (ADA/WCAG litigation exposure for a US e-commerce operator) and goes unused — see combined gaps.
- **[MINOR / PREMISE] Move 2 padded with phantom beneficiaries.** "Pays off for brands A/B and any future client": brand A is aquex.ai (Derek's own), brand B has no named consumer. The honest justification for Move 2 is PT alone.
- **[MINOR / EVIDENCE] Unverified specifics stated as fact:** Westpac GEL ships "exactly two npm packages"; Chromatic "free–$179/mo", zeroheight "$49/editor/mo", Tokens Studio "~EUR 17/mo" (stale-prone pricing, no verified tag); "nobody is selling generate-and-certify over MCP" (absence claim asserted as whitespace).

## Memo 2: Mobile

### What survived verification
The repo half is solid. Confirmed: zero breakpoint tokens; `src/styles/domain-contexts.css` has a single `@media` (forced-colors, line 323); the 16rem rail floor; Playwright and storycap pinned at 1280px; the Pagination "320px viewport preview" wrapper-div fake; LineChart's ResizeObserver (108–121); dashboard HTML's viewport meta + fixed `repeat(columns,1fr)` grid + 1200px nominal; hover→mouseover at `echarts-interactions.ts:~183` with zero touch/pointer handlers repo-wide; Button `md: h-10` (40px); the responsive-scorer trichotomy with no px definitions; the frozen never-consumed `RenderContext.viewport`; four Tailwind configs; and both `packages/tokens/scripts/build.mjs` and `style-dictionary.config.cjs` exist, so the crawl slice targets a real file.

### Findings

- **[MAJOR / EVIDENCE] "Exactly 4 CSS files contain width media queries" is false.** `apps/explorer/src/styles/index.css` has `@media (max-width: 960px)` at line 281 and `(max-width: 920px)` at line 1571 — six files, not four. The conclusion (no breakpoint system) stands, but this memo opens with a "verified, file:line cited" evidentiary banner; an "exactly" claim that fails spot-check taxes every other number in it.
- **[MAJOR / PREMISE] "Forge's own output is broken at phone widths today" never names who receives the broken shipment.** The dashboard-HTML fidelity gap genuinely hits agent consumers today. But the view-context collapse, drawer, and Storybook-viewport CRITs only bite when a human team views surfaces at phone width — i.e., they become urgent *if FRONT 1 happens*. The prerequisite claim ("responsive must be solid before any native conversation is honest") is asserted, not derived from a consumer. Each hardening item should be tied to PT-or-agent explicitly; as written, item 2 (the drawer) is partly Forge-internal polish.
- **[MAJOR / EVIDENCE] Dates and attributions in the tooling section need verification before presenting:** "Material iOS archived 2025-12-11" and "Salesforce native repos archived 2025-06-09" (specific dates, unverifiable here); "XcodeBuildMCP (Sentry-maintained)" — the project originated with an individual maintainer, so the Sentry attribution needs a source; "Maestro + its official MCP server (15.2k stars)" — 15.2k is plausibly the main Maestro repo's count attributed to the MCP server; Callstack's agent-device documented at `docs.expo.dev/agents/agent-device` — a Callstack tool on Expo's docs domain is an odd pairing, verify the URL exists and who owns the tool.
- **[MINOR / EVIDENCE] Style Dictionary version story mismatched with the repo.** "SD v5 ships iOS-Swift/Compose outputs natively" — Forge runs ^4.4.0, which already has those transforms, so the crawl slice stands, but the version claim should match the repo (same defect as Memo 1).
- **[MINOR / EVIDENCE] `resolveNetworkGridSpan` "nothing supplies it" is unproven.** It *is* invoked at `src/dashboard/widgets/network-widgets.tsx:174` with a `viewportWidth` argument; whether any upstream caller supplies that value wasn't shown. Verify before listing as dead plumbing.
- **[MINOR / EVIDENCE] "Fixed sizes with no measurement" slightly overstates.** Sankey et al. take width/height as props (`Sankey.tsx:64` is `DEFAULT_WIDTH = 900`); the defect is no self-measurement, not an immovable size.
- **[MINOR / COMPLETENESS] Unsized work:** crawl items 1–5 (the collapse + drawer is real engineering) carry no estimates; run-phase CI (paid macOS runners) and commercial Android live-screen a11y tooling (Deque/Evinced) are named but not costed.

## Gaps to close before presenting

1. **One merged timeline.** Both memos claim "now" from the same solo operator: Memo 1's Move 1 ("week 1–2") plus an unsized Move 2, and Memo 2's crawl ("now, regardless of everything else"). Derek needs a single ordered plan with rough effort per item and an explicit call on which front's first slice goes first.
2. **Money.** Zero commercial numbers anywhere: engagement pricing, retainer sizing, what Move 2 costs and whether it is recoverable if PT never signs, sandbox and CI costs. The open questions ask about shape but give no anchors to decide with.
3. **The idle/parked state.** Forge is idle with the flagship arc parked pending a real use case. PT is plausibly that use case; neither memo says so, nor what committing to PT does to the parked accuracy-pillar arc, nor what happens to the Move 2 investment if the engagement dies.
4. **Add "does PT need mobile?" to Memo 1's open questions.** Memo 2's entire walk/run gate hangs on PT mobile as the only candidate flagship consumer, but the client-facing question list in Memo 1 never asks it. This is the single concrete coupling between the fronts and it currently lives only in Memo 2.
5. **The ADA/WCAG angle.** PT is US e-commerce; accessibility-compliance exposure is the one place certify has a real client-side buyer. Both memos treat certify as Forge's differentiator without naming a client driver — adding this repairs Memo 1's certify premise and strengthens Memo 2's certify-first framing.
6. **Enterprise approval of the SaaS data path** (Tokens Studio sync, Chromatic, zeroheight) needs the same scrutiny Memo 1 applies only to Option 4.
7. **Source hygiene pass.** Verify or downgrade: atomize.tools effort estimate, newideamachine.com, pathtoproject.com, the CSA advisory citation, the 10–20% brand-cost figure, the pricing figures, the archive dates and star-count attributions, and the two absence claims ("no delivery literature shows...", "nobody sells generate-and-certify over MCP"). Fix in-text: Style Dictionary v4.4 (both memos), "exactly 4 CSS files" (Memo 2).
8. **Pilot fallback.** Memo 1's Move 3 pilot depends on registering the frozen parts-commerce model *and* on the Meridian Gate 5 boundary (open question 7). No fallback pilot surface is named if the boundary blocks reuse before reconciliation completes; Derek needs a default plan for "blocked."
