## 3. Settled decisions (build from these; do not reopen)

1. **No hosted CI.** Every gate is a local command. `pnpm viz:gate` (new `scripts/product-reality/s199-chart-gate.mjs`) is the per-change chart gate and runs in minutes. The five-suite capture runs once at close. `ci.yml` stays consistent for the two guards that read it, but nothing waits on it and nobody enables a workflow.
2. **The Sprint 198 carries come first** (m01), fixed at the producer and proven by assertions that check replacement, not presence, plus re-taken screenshots of only the affected checkpoints.
3. **Every pin moves at most once, attributed.** One ledger, `artifacts/product-reality/sprint-199/golden-ledger.json`, appended by each mission: file, pin, before, after, mission, reason. A pin moving twice is a finding. The migration scripts become sprint-parametric before any regeneration, so the sealed Sprint 195–198 receipts stay byte-identical (`git diff` under `artifacts/product-reality/sprint-19[5-8]` is empty at close).
4. **The Core Analytics Profile.** Waterfall (one MarkBar with explicit start/end) and histogram (pre-binned rows, x/x2) are built as pattern identities; no new chart type, so 13 stays 13. Multi-series and target close through their existing patterns. Candlestick, box and contour are retired, with reasons, through a served `retiredCells` record (the classification schema, generator, health schema and docs widened):
   - candlestick needs a V150 ranged-bar exclusion, a wick mark and an OHLC ordering rule;
   - box needs a rule/tick mark and a quartile rule;
   - contour has no isoline path in either engine.

   Result: 17 core cells, 17 surface-complete, 0 typed gaps, 3 retired. The financial and scientific family definitions are reworded to match.
5. **Patterns.** One scene path renders authored multi-mark, layout, interaction and y2 specs:
   - `translatePattern` returns a scene;
   - `viz.render` validates it, fills default axis titles, compiles through the Vega-Lite adapter, and adds a warning that static SVG shows the default selection state.

   The 8 existing public patterns keep the explicit path and their hashes. Layered params attach to the first layer unit; wrapped facets honor wrap/limit/maxPanels. Twelve authoring-only patterns go public. linked-brush-scatter retires through a served pattern `retired` status carrying its reason, and the recommender's cohort-scatter points at correlation-scatter. facet-target-band goes public or retires at its census measurement, with no third carry. sparkline-grid drops its redundant color encoding, which changes its source hash.
6. **High contrast for the nine types uses declared paints only.**
   - One HC-only ECharts chrome helper for title, legend and visualMap boxes, plus per-type fixes (sunburst and treemap level borders on `Canvas`, geo emphasis, sankey `source` link color, force_graph legend decided, treemap breadcrumb).
   - HC numeric colour becomes discrete steps using the declared literals verbatim: a piecewise visualMap for choropleth and bubble_map, a quantize scale for heatmap. The binned HC colour is stated.
   - Chord is decided from its forced-colours screenshot: rendered, or retired from HC with a typed reason.
   - A guard change (for example skipping `<clipPath>` children) happens only when no declared adapter option exists, and is named in the record.
   - The light/dark defects found in the same code are fixed in the same pass, each moved pin in the ledger: `[object Object]` hover fills, chord `stroke="source"`, treemap breadcrumb text, and heatmap's default ramp (it bakes the OODS sequential range).
   - Forced-colours browser proof covers all 13 types for both brands plus the HC dashboard (11 admitted panels).
7. **Bubble map sizes by area from zero.** The diameter is proportional to √(v/vmax), with no floor. V169 is rewritten to measure the drawn symbol sizes from the option `artifact.certify` already builds, never recomputed with the adapter's own function; a missing option means unresolved, never pass. The `src/viz` browser copy of the adapter is named as unchanged.
8. **ECharts bands and fidelity.**
   - ECharts renders y/y2 and x/x2 as a stacked pair with `stackStrategy: 'all'` and a precomputed difference column; tooltips show the raw bounds.
   - A per-renderer fidelity assertion joins the keystone gate: each example spec, rendered by the renderer `selectVizRenderer` picks, must use every declared channel. No allowlist.
   - Where ECharts cannot honestly render a pattern's layout, that pattern's `preferredRenderer` is corrected, with the reason recorded.
   - The ECharts cartesian path stays spec-only and uncertified, and the table says so.
9. **One graph placement.** A MarkGraph trait, a VizGraphPreview in React and Vue, and an `edge-array` chart source:
   - nodes are the sorted distinct ids;
   - links are directed, in row order;
   - a bidirectional flag adds the reverse link (dedupe an already-symmetric pair);
   - no invented value or group.

   Relationship is the one host. It gains a declared neighborhood edge array whose sample rows are labelled synthetic. The other seven ECharts types stay not-placed, each with its own reason (no object declares a hierarchy array, numeric link values or inline geometry), replacing the blanket `#1944` note.
10. **Timezone.** The field leaves ScaleTemporal: trait 0.3.0, a declared breaking change, with a decision superseding `#1969`. Axes stay UTC and no golden moves (the Sprint 196 cross-timezone probe confirms 16/16). The `#1971` limit is written into the public `viz.render` description, and the stale cookbook line is fixed.
11. **Soak.** The strict lower-bound assertion retires with its measurements retained (decision superseding `#1946`). The hard ceilings, disposal, fault cleanup, map bound, latency and concurrency stay pass/fail. Trend evidence is still emitted, and the soak runs locally once at close.
12. **One table.** `docs/api/viz-render.md` gains per-scope state for the 13 types: light/dark/hc × A/B, each rendered, typed-deferred with its code, or retired with its reason. It adds a conformant count and a per-row reason. Generation fails on any deferred scope without a code. "Certified" and "conformant" stay separate columns.
13. **Program rules.**
    - No consumer notices.
    - `builderSelfCertified:false`.
    - Boundary specs for every schema change; generated docs and registries only through their generators.
    - Rebuild viz-core before any mcp-server proof; narrow viz-core runs use `--coverage.enabled=false`.
    - Never build in the primary checkout (it serves the bridge).
    - The review closes the sprint and records carries; it never adds missions to this sprint.
