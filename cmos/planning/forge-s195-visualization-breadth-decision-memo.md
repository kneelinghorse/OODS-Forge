## 3. Settled decisions (build from these; do not reopen)

1. **Taxonomy is a generated, versioned artifact.** `packages/viz-core/src/registry/viz-taxonomy.v1.json` is produced by a script from three inputs: the registry, the 21 pattern specs, and ONE hand-authored classification table with its own JSON schema (the only place a human names a family). Every identity (13 types + 21 patterns = 34) belongs to exactly one family with a role `core|extension`. The Core Analytics Profile is the enumerated set of family cells that "core analytics" requires; each cell is `surface-complete` (a registry identity with public pixels) or a typed gap `{family, cell, reason}`. Financial and scientific are typed gaps this sprint; no new chart type is invented to fill them.
2. **Patterns become recipe identities with proof.** A sibling registry `viz-patterns.v1.json` (the 13-row file and its pins stay intact) carries one row per pattern: id, family, base chart type, spec sha256, portability, and a public pixel proof through `viz.render` by ONE deterministic translation from the patterns-v2 spec to the explicit input (implemented once in viz-core; no per-pattern hand-written inputs). `viz.render` gains an input `pattern` (the id) that resolves to that translation — a property with a read site and a boundary spec, per the Sprint 194 rule. A pattern the public path cannot express is typed `authoring-only` with the reason, never dropped.
3. **ECharts certification architecture: the declared operand profile, no Vega compile leg.** With the `data` operand, a11y-equivalence becomes a graded pillar on the ECharts path (the same 16 rules already evaluated warn-first), and `conformant` folds as a11y pass ∧ contrast not fail ∧ determinism stable ∧ accuracy evaluated-and-clean (`rulesEvaluated > 0`, none fired); `coverage:'certified'` on that path. The spec-only path stays `uncertified`/`null` with its note. bubble_map and flow_map gain accuracy rules (`OODS-V166+`, registered); force_graph gains a data-level rule or is typed-uncertified with the pinned reason that layout distortion is not detectable from data. A measured `conformant:false` is retained, never tuned away.
4. **HC pixels = the scope's CSS system-colour keywords, verified in a browser under forced colours.** `theme:'hc'` is admitted on `viz.render`, `dashboard.render` and `artifact.certify`; chart paints resolve from the HC token scope and are emitted verbatim (system-colour keywords or the scope's declared values) in the SVG; proof is Playwright with `forcedColors:'active'` in the existing theme harness, measuring computed paints. Certify's contrast pillar on `hc` is `'exempt'` typed `forced-colors` (no numeric claim); the other pillars are unaffected. If either SVG renderer rejects keyword colours, HC stays typed-deferred with the measured failure pinned — never a hex palette invented server-side (`#1851` stands).
5. **Role-A hue revision is a declared palette mover.** Categorical slot hues in the A/B light and dark sources move so min pairwise ΔE00 over CVD ≥ 10 with all 24 Role-C checks still ≥ 3:1; one-time golden migration with BEFORE/AFTER receipts (`#1850` pattern); historical matrix rows are superseded by reason, never re-baked silently. If 10 is unreachable with Role-C intact, the measured ceiling is pinned and the caution stays.
6. **Placement is a rule, not a hand-pick.** Any `Mark*` trait bound with a `chart` parameter projects its preview recipe into the detail (and dashboard, where the context exists) view extension through the same `parameter-applier` path area uses. At least bar, line and one ECharts family are placed on public objects whose traits declare suitable data; every other type records `not-placed` with a reason in the census. Generated React/Vue/HTML carry real renderer SVG; runtime cells are re-swept.
7. **Sprint 194 rules stay in force.** An input property that does nothing does not exist; every changed description or schema is pinned by a boundary spec and the tool ledger re-derives with all 19 advertised tools at product-reality tier; writes go to canonical source under env-overridable roots; zero hand-edited schemas or registry rows (registries are generated by census scripts); verifiers pin recorded heads (`#565`); pre-freeze verifier pass (`#574`); one five-suite capture under `#1833` (two attempts, decision receipt for a third); pace rule: no per-mission captures, no critic, no new closeout apparatus.
