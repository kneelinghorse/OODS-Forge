## 1. The problem (from the s139 review PS-2026-07-03-010)

s139 made `artifact.certify` grade the rendered compiled bytes, dissolving the classifier-mismatch false-pass for **single-layer** cartesian charts. The review (live-reproduced + source-confirmed) found two residual holes on the multi-mark / agent-IR surface certify exists for:

- **C1 (HIGH, correctness — a NEW false-`pass`).** `compiledColorUnit` (`certify-contrast.ts:140-153`) recurses into **only the first rendered unit** (`layer[0]` / facet `spec` / `concat[0]`). A hand-authored multi-mark IR — `marks[0]`=MarkLine `options.color:'#000000'` (passing) + no color encoding, `marks[1]`=MarkPoint `encodings.color` region-nominal whose baked `scale.range` FAILS role-C via a `config.tokens` override — compiles to `{layer:[passing-line, failing-points]}` and certify grades **only** `layer[0]`, returning `contrast:'pass'` on a chart that renders a real role-C failure. Reproduced live (aquex, `contentHash 8ed8e5fa`). Companion regression: a legit combo whose color-bearing mark is **not** first drops pre-s139 `'pass'` → `'unchecked'` (layer[0] is colorless).
- **C3 (HIGH, strategic — no puller).** `conformant` (`artifact.certify.ts:165-166`) is a11yEquivalence-**only**; `contrast` is assigned into `pillars` but never folded into the headline gate. grep-confirmed: `pillars.contrast` has **zero** programmatic readers, so an agent's `if(conformant)` still ships a `contrast:'fail'` chart. Three sprints (s137→s139) of contrast work drive no verdict any surface reads.

## 2. The decision (Derek-ratified)

Pair **[A] multi-mark UNION grading** (fix C1) + **[B] conformant-rollup** (fix C3), **sequenced A strictly before B**. A-before-B is **necessary and sufficient** (both critics confirmed): folding contrast into `conformant` while C1's false-`pass` still exists would propagate the false-clean into the gate every agent reads; after [A], `contrast` is the worst-of union so a multi-mark non-first-layer fail correctly reaches `conformant`.

Both changes are **certify-output-only** — certify is a verified **leaf** (nothing in viz-core/viz-render imports `certify-contrast` or `artifact.certify`; only doc comments reference them). No viz-core/viz-render source, no new tool (advertised set stays **25**), #110/#525 respected, pure/deterministic.

## 3. [A] Multi-mark union grading — design (`certify-contrast.ts`, m02)

**STEP 1 — plural walker.** Replace `compiledColorUnit(node)` (`:140-153`, first-unit-only) with `compiledColorUnits(node): CompiledUnit[]`. At any node: if `'mark' in rec || 'encoding' in rec` → return `[{mark, encoding}]` (Vega-Lite unit/layer/facet/concat are mutually exclusive, so the early return stays correct); else concat the recursion over **all** of: every element of `rec.layer[]` (NOT just `[0]` — the live C1 miss at `:146`), `rec.spec` (facet), and **every** element of each `hconcat`/`vconcat`/`concat[]` (NOT just `[0]`). Covers all 6 shapes the adapter emits (verified vs `vega-lite-adapter.ts:99-147` + `vega-lite-layout-mapper.ts:28-132`): (1) top-level `{mark,encoding}`; (2) `{layer:[...]}` when `requiresLayer` (marks>1 OR any layer has `.data`); (3) facet `{facet, spec:{mark,encoding}}`; (4) facet `{facet, spec:{layer:[...]}}`; (5) `{hconcat|vconcat|concat:[...]}`; (6) concat-of-layers. Nesting is **depth-2 bounded** (the primitive threaded into facet/concat is never itself a facet/concat — layout is single-trait dispatch), so recursion terminates. Guard empty arrays → yield nothing.

**STEP 2 — per-unit grader.** Extract the four-case body (`:220-265`) into a pure `gradeUnit(unit, spec, canvasHex): ContrastPillarResult | undefined`:
- **CASE 1** (`colorEnc.scale.range` → categorical, sliced to `distinctCount` cardinality): **identical** semantics.
- **CASE 2** (single-series `unit.mark.color`): **CHANGED per the CASE-2 fork (Derek: "grade OODS series colors only").** Grade `mark.color` for role-C **only when it equals the resolved categorical-01 slot** — `mark.color === resolveSlotHex(categoricalToken(1), overrides)` (override-aware, so a `config.tokens`-poisoned categorical-01 still matches → graded → fails correctly). If it does **not** match, the unit is a **neutral skip** (an author-supplied decorative/annotation color = chrome, OOS per s138). This reuses the C2 label-derivation helper. Rationale: certify's contrast pillar grades the OODS **data-series** colors, not chart chrome; a faint reference/annotation line must not flip a legit chart to `contrast:'fail'`. Accepted cost: a single-series chart whose author overrode the mark to a non-OODS brand color reports `contrast:'unchecked'` (honest — you opted out of OODS grading), not a graded verdict.
- **CASE 3** (`colorEnc` present, no palette → `exempt`): **identical**.
- **CASE 4** (no color in THIS unit): return **`undefined`** — a NEUTRAL no-op, **NOT** `'unchecked'`. Load-bearing: the companion regression (color-bearing mark not first) has a colorless `layer[0]` that must be **skipped**, not poison the verdict.

**STEP 3 — combine.** `evaluateContrastPillar` (`:215-266`) resolves `canvasHex` + `overrideMap` **once** (`:233`), then `graded = compiledColorUnits(compiled).map(u => gradeUnit(u, spec, canvasHex)).filter(defined)`. If `graded` is empty → the existing whole-chart `'unchecked'` note (preserves single-unit CASE 4 byte-for-byte). Else COMBINE via the worst-verdict lattice below.

### 3a. Worst-verdict lattice (resolved fork)
RANK (higher wins): **`fail`=3 > `unchecked`=2 > `pass`=1 > `exempt`=0**. Combine = max-rank across graded (non-neutral) units; ties → **first in walker document order** (deterministic). Carry the winning unit's `contrastNote`.

**Soundness (both critics confirmed in source):** a graded unit returns `'unchecked'` iff `!canvasHex` (`gradeCategorical`, `:162`), and `canvasHex` is resolved **once globally** (`:233`), independent of any unit — so graded-`'unchecked'` is **all-or-nothing** and never mixes with a real `pass`/`fail`. The `fail>unchecked>pass>exempt` vs the simpler `fail>pass>exempt` orderings are therefore **provably identical on every reachable input**; we pick the defensive one (a withheld canvas claim shouldn't read as an affirmative pass). Edge cases pinned: `fail+pass`→`fail` (C1 fixed); neutral-skip + categorical-pass→`pass` (regression fixed); `exempt+pass`→`pass` (a graded categorical dominates a gradient; `exempt` only when ALL color units are gradients); `exempt+fail`→`fail`; all-neutral / empty concat container → `'unchecked'` (no crash); facet-of-layer / concat-of-layer → recursion reaches every leaf. Role-A distinguishability stays **per-unit** (strictly more correct than the old single read). **Note-carry tie-break polish DROPPED** (critic amendment 4) — keep the combine dead-simple first-max-wins; `contrastNote`-only polish for no verdict change is not worth the branching.
