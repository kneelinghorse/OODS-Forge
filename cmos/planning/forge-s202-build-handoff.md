## Hazards and recipes

- **Default CSP.** No `blob:`/`data:` scripts, no `eval`, no network: inject compiled code as inline `<script>` text; the runtime must be inlined in the shell; assert zero `securitypolicyviolation` events in the harness.
- **One React, one Vue.** The `iife` artifact must bind `react`, `react-dom/client`, `vue` and the `@oods/*` packages to the shell's inlined runtime globals, or hooks and reactivity break; an esbuild plugin resolving bare imports to `window.__oodsRuntime[...]` is the mechanism.
- **Host caching.** Claude Desktop caches `ui://` resources by URI; put the build revision in the shell's URI and say "Reload MCP Configuration" in `install.md`.
- **Negotiation.** Advertise `_meta.ui.resourceUri` only when the client's `capabilities.extensions["io.modelcontextprotocol/ui"]` is present; log the client name and the negotiation to stderr (never stdout).
- **Adapter stdout.** JSON-RPC only; the host and the harness relay log to stderr.
- **SDK line.** `@modelcontextprotocol/ext-apps@1.7.5` only in the built app and the harness; the adapter stays on `@modelcontextprotocol/sdk` 1.x; the 2.0 SDK line is a later decision.
- **Reference host ≠ real host.** A green harness proves the protocol and the sandbox; the Claude Desktop and Cursor renders are Derek's runs, recorded by the review; never claim them.
- **Sealed receipts.** `artifacts/product-reality/sprint-195..201` never change; `git diff --stat` under them must be empty at every commit.
- **`--final` assembly refuses a dirty tree; the capture needs a clean tree at every checkpoint.** Commit first, write logs outside the worktree.
- **Per-sprint modes and paths** to bump: `s199-chart-gate.mjs` boundary, `s195-viz-matrix`/`s195-qualify-viz-matrix` modes, `s196-release-readiness` FACTS_PATH, `s193-tool-truth` PORTABLE_RECEIPT_PATHS + `tool-ledger.ts` + `tool-truth.s193.spec`; part B needs the server and bridge dists rebuilt at the frozen head; the five-suite capture is `capture-s185-m01-baseline.mjs` then `s200-capture-accounting.mjs`.
- **Roadmap edits.** Only the top part of `near.md`; rerun the near.md-reading specs after any edit.
- **Out of bounds.** No messages to any project. No publish, tag or release. No Stage1, aquex or host-config changes. No content Derek did not state.
