### s102-m02 — Branded Mockup Emitter (third runPreEmit() consumer)

**Track:** Capability
**Status:** Completed 2026-05-20 (commit `ebd2ee6` — handoff checkpoint, cross-machine)

Emitter at [packages/mcp-server/src/codegen/branded-mockup-emitter.ts](../../packages/mcp-server/src/codegen/branded-mockup-emitter.ts) (444 lines). Self-contained HTML+CSS document; branded card layouts driven by `oods.render.brand_overlay`; CSS custom properties scoped via `:root` for default brand-a and `[data-resolved-brand="X"]` for non-default brands actually used in a given emit.

**Brand-overlay resolution chain:** `options.brandOverlay` (per-emit override) → catalog entity `brand_overlay` → `DEFAULT_BRAND=brand-a`. Unknown overlay names emit `OODS-BM-002` warning AND fall back to brand-a per Rule 12 (fail loud) so the render still succeeds.

**Slot-kind visual dispatch:** `image` / `heading` / `subheading` / `body` / `meta` / `price` / `status` / `action` / `generic` drive presentation only; `data-slot-name` + `data-slot-field` emit verbatim regardless of kind. `data-slot-kind` added as a non-contract attr for downstream tools that want the visual classification without re-parsing slot names. Kind inference is name-based and lives inline in the emitter; no shared abstraction extracted (n=1 consumer per Rule 2).

**Cross-emitter contract parity:** [test/contracts/emitter-data-attr-parity.spec.ts](../../packages/mcp-server/test/contracts/emitter-data-attr-parity.spec.ts) (130 lines) runs all three C-track HTML emitters (boxes-arrows, wireframe, branded-mockup) against `content-pack` + `billing-multi-entity` fixtures and asserts the data-* contract holds verbatim across all outputs.

237 unit tests + 229 Q3 E2E tests via jsdom. **Decision #525 (D2 third-validated cleanly):** runPreEmit() consumed unchanged; PreEmitContext / CatalogAnnotations shape required zero modifications even on the visual-polish dimension.

### s102-m03 — A2UI Runtime Composition Prototype (fourth runPreEmit() consumer)

**Track:** Capability
**Status:** Completed 2026-05-20 (work in working tree pending m04 closeout commit)

**Mission-start A2UI-spec audit** (non-optional discipline per mission spec; captured BEFORE any emitter code per Rule 1): A2UI v0.9 at [github.com/google/A2UI/tree/main/specification/v0_9](https://github.com/google/A2UI/tree/main/specification/v0_9) status "closed" (frozen, no further v0.9 edits; contributions redirected to v0.10). v0.8 was prior Public Preview; v0.9 is the version Google ADK's `A2uiSchemaManager` + the March 2026 ecosystem (Mete Atamel ADK blog) actively target. Host implementations: ADK + Lit web renderer + Flutter GenUI SDK; SDKs in TypeScript/Python/Kotlin. No public live host endpoint Forge can POST to (contrast with Concordance) — conformance test is JSON-Schema-validation-based, not live-host-based. **Verdict: IMPLEMENTATION path; memo-only path NOT triggered.**

**Vendored schemas** (real-world fixtures, not self-invented) at [packages/mcp-server/src/a2ui/contracts/v0_9/](../../packages/mcp-server/src/a2ui/contracts/v0_9/) — `server_to_client.json` (CreateSurface / UpdateComponents / UpdateDataModel / DeleteSurface envelopes; `version: const "v0.9"`), `common_types.json` (ComponentCommon, DataBinding {path: JSON Pointer}, DynamicValue, DynamicString/Number/Boolean/StringList, ChildList, FunctionCall, Action, AccessibilityAttributes), `catalogs/minimal/catalog.json` (Text/Row/Column/Button/TextField with CatalogComponentCommon `weight`). Byte-identical to upstream per sprint-97 m02 vendoring-discipline pattern; version policy applied at the application layer.

**Emitter** at [packages/mcp-server/src/codegen/a2ui-runtime-emitter.ts](../../packages/mcp-server/src/codegen/a2ui-runtime-emitter.ts) — fourth runPreEmit() consumer, first JSON-output emitter, first consumer where the OUTPUT FORMAT axis fundamentally changed (HTML → JSON message stream). Projects `entity.oods.render.slots[]` → flat A2UI `components[]` with `id` + `children` refs; `slot.binding.field` → A2UI `DataBinding {path}` via dot-path → JSON Pointer translation (handles array indices `[N]` + RFC-6901 escape `~→~0` `/→~1`); `oods.projection_variants[].surface` → A2UI `surfaceId`; `entity.urn` → `catalogId "oods-forge:<urn>"`; `brand_overlay` → `theme.primaryColor` via brand-hex map (`brand-a → #1351c4`, `brand-b → #1e8f4a`, fallback `#1351c4`). Per-variant emission iterates all `projection_variants` when `options.variant` is unset; root is a Column with ChildList of slot ids; accessibility.label propagated to every slot component.

**Catalog targeting:** A2UI minimal catalog only (Text/Row/Column/Button/TextField). Image slots fall back to Text via DataBinding URL with per-occurrence `OODS-A2UI-IMAGE-FALLBACK` warning per Rule 12 (fail loud, not silent fix). Image-component extension named as two future moves (custom catalog declaring Image atop minimal via `acceptsInlineCatalogs:true`, OR target richer A2UI basic catalog) — neither sprint-102 work.

**Tests:** 26 unit + 98 Q3 E2E AJV-validated against all 8 fixtures (user, product, subscription, billing-multi-entity, content-article, content-author, content-comment, content-pack). AJV setup registers minimal catalog under the relative-resolved URL `https://a2ui.org/specification/v0_9/catalog.json` so `$ref: "catalog.json"` in `server_to_client.json` resolves cleanly.

**Cross-emitter parity test NOT extended** (decision captured this session): A2UI emits JSON not HTML so the DOM-query-shaped contract doesn't generalize. A2UI's structural contract (entity URN → surfaceId, slot name → component id, slot field → DataBinding.path) is asserted inside its own Q3 gate. Rule-of-three for a generalized semantic-anchor contract would fire if a second JSON-shaped emitter ships.

**Strain assessment — D2 abstraction FOURTH-validated cleanly, IR-memo trigger from decision #450 did NOT fire.** Zero modifications to `pre-emit.ts` / `CatalogAnnotations` / `PreEmitOptions` / `runPreEmit()` signature. First validation across an output-format axis change. Per-variant emission still uses the s100-m03 `selectVariant()` pathway unchanged. The A2UI-specific projection work (path translation, slot-kind dispatch, root-Column synthesis, accessibility-label propagation, brand-hex resolution) was entirely emitter-local. **Strong confirmation that the per-fidelity emitter + shared pre-emit pass pattern was correctly factored.**
