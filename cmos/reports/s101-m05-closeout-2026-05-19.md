## Mission Deliverables

### s101-m01 — C3 Operator Workflow Tool Surface (`review.triage`)

**Status:** Completed
**Branch state:** Code + 22 unit tests + 3 contract tests + 2 conflict-artifact fixtures + auto-regenerated `docs/api/review-triage.md`.

**Shipped:** `packages/mcp-server/src/tools/review.triage.ts` (~360 LOC). Loads conflict artifacts at `.oods/conflicts/{...}.json`, accepts `decisions[] = {objectId, verdict: 'accept'|'patch'|'defer'|'dismiss', reason?, patchOverrides?}`, additively mutates the artifact with `resolution_status` / `resolved_at` / `resolved_by` / `operator_reason`, and routes accept → `map.create` + patch → `map.update`. Defer and dismiss are local-only per the mission spec.

**Path safety mirrors `concordance.validate.ts`:** absolute paths / parent-traversal / project-root escape / missing files / corrupt JSON / wrong-kind-header all rejected up front before any mutation runs.

**Idempotency invariant:** re-running with the same decision payload is a no-op and surfaces already-resolved items as `errors[]` entries with `kind='already_resolved'`. Atomicity: per-decision `map.*` failures are non-fatal and the item's `resolution_status` stays `'open'` so a retry can succeed without losing artifact state.

**Conflict-artifact schema extended additively:**
- `RemediationHint` (kinds: use_alternate_interpretation / merge_with_existing / reject_low_confidence / manual_patch / split, with confidence + reasoning + optional refs)
- `ConflictResolutionStatus` (open | accepted | patched | deferred | dismissed)
- `ConflictArtifactItem` (with `remediation_hints?[]`, `resolution_status?`, `resolved_at?`, `resolved_by?`, `operator_reason?`)
- `ConflictArtifact` (top-level shape with all the above)
- Full `ReviewTriageInput/Output/Decision/Error` payload types

`map.apply.ts` `writeConflictArtifact` now populates `remediation_hints[]` per item via a new `buildRemediationHints()` helper (1–3 hints per item, ordered by confidence desc). `resolution_status` defaults to `'open'`.

**Registered in all five required places:** `registry.json`, `registry.ts` FALLBACK, `index.ts` toolSpecs, `security/policy.json` (allow=maintainer, write tool), `mcp-adapter/tool-descriptions.json`. JSON input/output schemas at `packages/mcp-server/src/schemas/review.triage.{input,output}.json`.

**22 unit tests** cover: input validation, 5 path-safety rejections, each verdict ×2 fixtures, idempotency, item-not-found, invalid-verdict, atomicity-across-batched-decisions, dismiss-does-not-call-map.delete, defer-does-not-call-map.*, remediation_hints preservation.

**3 round-trip contract tests** at `test/contracts/review-triage-roundtrip.spec.ts` cover: map.apply→artifact with remediation_hints[] populated and confidence-desc-ordered + status='open'; mixed patch+defer batch mutating both registry and artifact; full idempotency at the contract level.
