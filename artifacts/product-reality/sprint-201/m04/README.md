# s201-m04 — Measurement beside the render

Builder self-certified: **false**. Built on `codex/sprint-201-design-surface` from `680c5f9e4` (m03). Receipts were taken from the dirty working tree before this mission's commit.

## What is in the tree

- **Stored on the version, exactly as the tools return it** (`packages/mcp-server/src/tools/design.preview.ts`, `lib/measurements.ts`, `codegen/chart-assets.ts`): the `code.generate` `validationReceipt` per framework (the checks that ran and `notChecked`) at generation time; `artifact.certify` for every placed chart, once per version, by re-rendering each generation request (`placedChartRequests`, extracted from `prepareChartAssets` so what is certified is what was placed) with its normalized spec in the version's brand and theme; and axe-core results posted back by the running page per framework, brand and theme. The render output gains `measured` (`validation`, `charts` counts, `axe` scopes, and `notMeasured`, which lists every measurement the version does not carry).
- **axe-core in the running page** (`packages/mcp-bridge/src/preview/page.ts`): after every mount, including a brand or theme re-mount, the page imports the bundled `axe.js` (axe-core 4.11.0, now in the host runtime and the closure: 314 → 315 packages, notices regenerated), runs it on the document in the scope it is mounted in, posts `{engine, framework, brand, theme, violations (id, impact, help, tags, node count, first targets), passes, incomplete, inapplicable}` to `POST /preview/<id>/<n>/measurements/axe`, and tells the parent page. The host validates the shape (`parseAxeResult`), refuses a framework the version was not generated for (409), and writes `measurements.axe[framework][brand/theme]` atomically with the schema asserted unchanged (`writeVersionMeasurements`). A runtime built without `axe.js` leaves the page without an axe run and the panel says so.
- **The measurement panel** (`measurements.ts`, on the version page and both sides of the compare page, refreshed in place when the page reports a measurement): the generation receipt per framework, every placed chart's verdict (conformant / not conformant / not on the certified path), coverage, pillars and findings count, and axe per framework and scope with violations, passes, incomplete and inapplicable; every measurement not taken is a `data-oods-not-measured` row reading "not run", with the count on the section. `GET …/measurements` returns the panel, `…/measurements.json` the raw record.
