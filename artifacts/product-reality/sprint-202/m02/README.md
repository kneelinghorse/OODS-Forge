## What is in the tree

- **The adapter** (`packages/mcp-adapter/index.js`, helpers in `mcp-apps.js`): capabilities `tools`, `resources` and `extensions["io.modelcontextprotocol/ui"]`; `resources/list` names one resource, the preview app `ui://oods-forge/preview/<revision>/app.html` (`text/html;profile=mcp-app`; the revision is the app's content hash, so a host that caches by URI refetches when the app changes, and a stale revision is refused with the reload advice); `resources/read` serves the app, the compiled composition modules `ui://oods-forge/compositions/<id>/<n>/<react|vue>.js[?brand=&theme=]` (the `iife` compile, `text/javascript`) and their styles (`.css`), the version record (`…/<id>/<n>/record.json`: lineage, schema, model, artifacts, measurements) and the lineage list (`…/<id>/versions.json`), all through the lazily started preview host. The client's `initialize` is read raw at the transport (the SDK's capability schema drops unknown keys such as `extensions`): when `capabilities.extensions["io.modelcontextprotocol/ui"]` is present (or `OODS_MCP_APPS_UI=1` forces it), `design_preview` carries `_meta.ui.resourceUri` (and the 1.x-line key `ui/resourceUri`) in `tools/list`; every other client keeps the Sprint 201 text result. Every `design_preview` result carries `structuredContent` beside the unchanged text: the result itself, plus `resources` (the app, the record and versions resources, the module and style URIs for the requested scope) when the app was offered. stderr names the client, the protocol, whether the extension was negotiated and whether the app was offered; stdout stays JSON-RPC only.
- **The iife compile** (`packages/mcp-bridge/src/preview/compile.ts`, `format: 'iife'` on `module.js`): bare imports become the inlined runtime's globals (`globalThis.__oodsRuntime[<specifier>]`, a CommonJS shim so named and default imports resolve through esbuild's interop, refusing loudly when the runtime lacks a specifier); the exports land on `__oodsModules.m_<artifact hash>` (`module-globals.ts`), so two versions side by side never collide; `styles.css` serves the artifact's own stylesheets. The esm compile is unchanged and cached separately.
- **The preview app** (`packages/mcp-bridge/preview-app/`, built by `scripts/build-preview-app.mjs` into `dist/preview-app/app.html` with `manifest.json`): connects to the host (`ui/initialize`), shows the version the tool result names and the host context, reads the compiled module through `resources/read` and reports it. The build inlines, beside the app script (SDK 1.7.5, 401,799 bytes), the runtime a generated app runs on (`globalThis.__oodsRuntime`: React 19.2.0, ReactDOM, Vue 3.5.42 and the foundation packages, 1,504,459 bytes; axe-core left out) and the preview runtime's CSS (162,876 bytes): **2,069,958 bytes**, revision `8f9ffcf83d3c`, no CSP declared, no network reference; the markers are replaced with functions so the bundles' `$&` survives. The app alone was 402,564 bytes when first built; the runtime is inlined here so m03 mounts the running app from it.
- **The reference host** (`scripts/product-reality/s202-reference-host.ts` with `reference-host/host.ts` and `reference-host/sandbox.html`): Chromium, the host page and the sandbox page on two `127.0.0.1` origins, the sandbox served with the spec's default policy as its `Content-Security-Policy` header (the document written into the inner iframe inherits it; `securitypolicyviolation` events are relayed and counted), the SDK's `AppBridge` with a `PostMessageTransport` on the host page, `tools/call` and `resources/read` relayed to the real adapter over stdio, every act recorded. It fails when the extension was not negotiated. Exported for specs and usable as a CLI for receipts.
- **Proofs and the bundle**: the clean-HOME proof records `initialize.capabilities`, the tools carrying `_meta.ui` and the adapter's negotiation receipt; the s196 native-error script copies the new helper module; the bundle assembler ships `mcp-apps.js` with the adapter and allows the component-contracts provenance string inside `preview-app/app.html` (the app inlines that runtime, as `preview-runtime/oods-component-contracts.js` already did); `THIRD-PARTY-NOTICES.md` is regenerated because the lockfile moved (the MCP Apps SDK as a devDependency at the root and in the bridge): the same 315 packages, only the recorded lockfile hash changed.
