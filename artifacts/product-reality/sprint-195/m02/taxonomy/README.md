# s195-m02 taxonomy evidence

The generated census classifies 34/34 source identities: 13 measured chart types and 21 exact pattern specifications, across eight families. The 20 enumerated core cells contain 11 surface-complete cells and nine typed gaps. All checks in `verification.json` exited 0; the focused contract ran 21 tests with none skipped.

- `taxonomy-census.json` is the generated canonical artifact retained with this mission.
- `contract.log` records identity coverage, invalid assignment rejection, same-cell public backing, raw spec SHA pins, and stale artifact/document/source controls.
- `check.log` records byte-identity verification of both generated outputs.
- `typecheck.log` records the isolated generator check under strict NodeNext settings.
- `verification.json` records the fixed mission baseline, checked source hashes, commands, statuses, and summary. The source was checked in the working tree; the baseline is not presented as a committed implementation head.

Each identity has one primary core cell. A cell is complete only when an identity assigned to that same family and cell carries `publicSvg:true` in the measured type registry. Pattern specifications carry `publicSvg:false` until exact public proof exists; their base types cannot supply that proof. The generic heatmap remains an extension with no primary core cell because its measured revenue-intensity fixture does not establish distribution semantics. The line type's primary cell is trend, so its pixels do not silently fill the distinct multi-series cell. Financial candlestick/waterfall and scientific box/histogram/contour remain explicitly typed gaps.

These checks establish the taxonomy contract and reproducibility. They do not perform a new public rendering census, portable capture, sprint closeout, or independent certification.
