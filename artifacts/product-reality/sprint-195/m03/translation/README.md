# Sprint 195 m03 — authored pattern translation

The package now bundles all 21 exact `pattern:viz:*` source identities and their original-byte SHA-256 pins. `scripts/product-reality/s195-pattern-sources.ts` derives the package-owned JSON from the authored specs, validates their IR, rejects unknown identities/paths and duplicate sources, and joins recommender base types by source path. This preserves the source `pattern:viz:linked-brush-scatter` identity rather than exposing the recommender's `cohort-scatter` alias. `--check` requires byte-identical generated output; `--root` or `OODS_VIZ_PATTERN_SOURCE_ROOT` controls the output root.

`translatePattern` accepts an exact source id or normalized spec and returns either explicit input plus internal presentation, or a typed authoring-only result with concrete reasons. Detection is property-based: multiple marks, layout composition, interactions, transforms, external/named data, secondary positional channels and unmapped mark options never silently flatten into a simpler chart. It does not use an identity blacklist.

The eight source-level renderable patterns are simple-bar, stacked-bar, stacked-100-bar, diverging-bar, running-total-area, correlation-scatter, time-grid-heatmap and correlation-matrix. All other 13 retain their source identities and explain their structural/interaction gaps. Public pixel/certification evidence is generated by the separate public-handler census, not inferred from this translation count.

`applyPatternPresentation` returns a fresh validated IR. It preserves original dimensions and padding, accessibility metadata, portability/table-column order, legends, mark options and mark-specific encoding precedence. Builder-inferred types and accessible default labels remain where the source supplied no value. Existing adapter support consumes the running-total area's monotone curve/zero baseline; the translator adds no cumulative or normalization transforms to already cumulative ARR/already normalized shares.
