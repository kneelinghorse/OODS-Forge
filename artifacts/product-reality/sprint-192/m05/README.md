# s192-m05 — the three retained component roots

AuditSummaryCard, SortIndicator and TimelineEntryLabel are governed root exports in React and Vue, with HTML mappings, v1.1 structured contracts, shared executable scenarios, accessibility, interaction and six-scope theme evidence. Both readiness documents contain 75 eligible roots. Catalog/export projection remains m06 work. Decision #1888 records aggregation, control ownership and recipe semantics.

AuditSummaryCard counts object records, derives the latest valid UTC instant independently of input order, and uses that record’s actor. Invalid timestamps cannot become latest; lastN limits recent labels rather than the total. Empty values say “Not recorded”. The declared detail extension and this mission require a static summary. Older Auditable accessibility prose about expansion has no corresponding state/control declaration; it is a documentation conflict for later reconciliation, not an implemented expansion claim.

SortIndicator owns a native button in a scoped column header, exposes aria-sort and cycles none → ascending → descending → none through Enter, Space or pointer. It emits the structured state; the consumer owns record sorting. Binary mode, authored-state updates and exact event operands are tested. TimelineEntryLabel delegates to InlineLabel, defaults compact truncation to 40, and preserves explicit limits, full mode, authored content precedence and the public component ID.
